Apice Memory Atlas

Calendar News Activity

The Apice Memory Atlas collects stories of the former residents of Apice Vecchia, linking each memory to the house, street or courtyard it belongs to.

These personal fragments become part of an interactive map, where visitors and locals can explore the historic town house by house and read the stories connected to each place.
